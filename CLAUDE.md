# aithemes

## О проекте
Вертикальные ролики в формате «симулятор ситуации по минутам»: зритель проживает историю от второго лица («ты»). Темы и жанры разные, общий у роликов узнаваемый графический стиль и подача. Ролик может быть самостоятельным или частью серии. Длительность сюжета ровно 1:50, плюс 2 секунды финальной карточки «Продолжение в профиле» (итого 1:52). Видео собирается программно, озвучка генерируется через ElevenLabs.

## Стек генерации видео
Всё рендерится кодом в папке `render/`, без внешних видеосервисов.

- **Окружение:** macOS, Node, ffmpeg (libx264, libmp3lame), npm-пакет `@napi-rs/canvas` (Canvas 2D на Skia, уже установлен в `render/node_modules`). Python без PIL и sox не нужны: звук синтезируется в Node.
- **Шрифты** системные, подхватываются сами: `Inter` (кириллица, текст и плашки), `JetBrainsMono Nerd Font Mono` (цифры HUD и таймеров). Полный список: `node -e "console.log(require('@napi-rs/canvas').GlobalFonts.families.map(f=>f.family).join(', '))"`.
- **Принцип:** кадр — чистая функция от времени `t`. Нет состояния между кадрами, нет `Math.random()`/`Date.now()` в контенте (только seeded `rng`). Поэтому кадры можно рендерить параллельно и в любом порядке, а контрольный кадр совпадает с кадром в итоговом видео.

**Общее (переиспользуется в любом ролике):**
- `render/render.js` — рендер: canvas 1080×1920, 30 fps → сырые RGBA в ffmpeg, N воркеров по диапазонам кадров, склейка частей, затем звук: фон → `tmp/video.mp4`, фон + голос → `tmp/video_voice.mp4` (превью для проверки синхрона).
- `render/lib/core.js` — математика, easing, seeded rng и шум, цвет, примитивы, свет (`glow`, `pool`, `beam`), туман, частицы, текст, камера. Палитра `P` в нём — палитра серии 1.
- `render/lib/overlay.js` — плашки, глитч, вспышка, зерно и сканлайны.
- `render/lib/tl.js` — общая логика таймлайна: поиск сцены, глитч на склейках, эффекты битов, 0.1 с черноты перед финальной карточкой.
- `render/lib/endcard.js` — финальная карточка «Продолжение в профиле»; цвета и свой элемент (`extra`) задаются под стиль ролика.
- `render/audio.js` + `render/lib/sfx.js` — синтез фона: тон, шум, щелчок, удар, нормализация к пику −11 dBFS → `tmp/outer.mp3`.

**Своё у каждого ролика — папка `render/epN/`:**
- `timeline.js` — сцены `[id, t0, t1]`, состояние HUD по сценам, плашки, биты эффектов. Экспортирует `DURATION`, `sceneAt(t)` → `{t0, t1, draw(ctx, lt, t, d)}`, `hudAt(t)` → состояние или `null`, `drawHUD(ctx, st)`, `fxAt(t)` → `{shake, glitch, flash: [цвет, сила], punch, black}`, `plates` → `[{t0, t1, text, color}]`.
- `scenes_*.js` — отрисовка сцен; `art/` — ассеты и HUD в стиле этого ролика; `audio.js` — звуковые события: `(mix) => { …; return { gain: t => множитель } }`.
- **Новый ролик начинается с копии заготовки:** `cp -R render/ep_template render/epN` (N — следующий свободный номер). Заготовка сразу рендерится: сцены-заглушки, HUD (время + показатель), пример плашки и битов, палитра `palette.js`, фоновый звук, финальная карточка на 110–112 с. Дальше по раскадровке заменяются сцены в `scenes.js` (можно разбить на `scenes_a/b.js`), список `S`, `plates` и `beats` в `timeline.js`, подписи и показатели в `art/hud.js`, звуки событий в `audio.js`. Сцену финальной карточки (id 99) и вызов `makeTimeline` не трогать.
- Готовые ролики (`render/ep1`, `render/ep2`, …) — авторские исходники, в репозиторий не попадают (`.gitignore`) и могут отсутствовать. Если такая папка есть, это законченный пример наполненной заготовки: можно подсмотреть приёмы, а ассеты из её `art/` брать только для продолжения той же серии. Если папок нет, работай от `ep_template` — её достаточно.

**Команды** (из `render/`; проверить, что всё работает, можно на `--ep ep_template`):
- `node render.js --ep epN --still 1.5,12,40` — контрольные кадры в `render/out/stills/` и контактный лист `render/out/sheet.png` (смотреть его, а не каждый кадр).
- `node audio.js --ep epN` — фоновый звук.
- `node render.js --ep epN --workers 8` — полный рендер (около 1.5 мин на 1:52). Сначала звук, потом видео: склейка берёт готовый `tmp/outer.mp3`.
- `render/out/` — черновики (кадры, части видео), можно удалять.

## Порядок работы
- Приветствие и пересказ пользоватюлю этого блока (расскажи что вы сейчас будете делать).
- Запусти скилл *nolan*
- Когда *nolan* отработал - сохрани его результат в tmp/nolan.txt по его результатам запусти скилл *voice*
- Когда *voice* отработал - по его результатам запусти скилл *genvideo*
- Спроси у пользователя как назвать папку с результатами и перемести туда файл tmp/video.mp4, tmp/voice.mp3, tmp/nolan.txt и tmp/outer.mp3
- Удали папку tmp.
- Если это была финальная серия - удали из папки render ассеты, которые касаются этого сериала. Сгенерируй простые превью (формат 3:4) для каждого видео и положи его в папку с результатами. Оставь только render/ep_template . Также удали из общей памяти информацию именно о сюжете этого сериала.
